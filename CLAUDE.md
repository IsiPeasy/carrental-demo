# CLAUDE.md — carrent-demo

Multi-theme design demo for **Rial Rent** (rialrent.it): one site, five styles. Same data, same pricing, same store; each style changes skin, typography, motion and one or two signature interactions. Full brief: `BRIEF.md` (IT).

## Stack (non-negotiable)
- Next.js 15 App Router, TypeScript strict, `output: 'export'`, `trailingSlash: true`, `images.unoptimized: true`
- Tailwind CSS 4 (`@theme` in `app/globals.css`, no tailwind.config)
- three.js only (no R3F/drei/GSAP). `three/examples/jsm/*` addons are part of the `three` package and allowed.
- Zustand (+ `persist` → localStorage for builder state, locale, admin rate overrides)
- Fonts: `next/font/google` only (declared once in `lib/fonts.ts`)
- Playwright: devDependency, QA only
- TypeScript is pinned to 5.x (Next 15 needs the TS JS API; TS 7 native port breaks it).
- **No other runtime dependency.** Exception: Natural Earth 1:50m countries (public domain) cropped to Europe in `public/geo/europe.json` (generated by `scripts/crop-geo.mjs`), projected by hand in `lib/geo.ts`. No d3.

## Commands
- `npm run dev` — dev server
- `npm run build` — static export to `out/` (must stay green after every phase)
- `npm run lint` — `tsc --noEmit`
- `npm run qa` — Playwright screenshots → `qa/screenshots/` (needs `npx serve out` or dev server on :3000; see script header)

## Theme registry rules
- `type StyleId = 'nocturne' | 'riviera' | 'grand-prix' | 'itinerary' | 'marque'`.
- Each theme in `lib/themes.ts` has: `slug`, `name`, `tagline {it,en}`, `audience {it,en}`, `tokens` (colors, fonts, radius, motion), `components` map, `scene3D` (default `Car3D` props).
- Component map keys: `Hero`, `HomeSections`, `FleetSection`, `CarStep`, `DestinationStep`, `DatesStep`, `ExtrasStep`, `SummaryVariant`, plus `BuilderLayout`, `Header`, `Footer`, `Door` (landing mini-hero). Missing keys fall back to `components/neutral/*`.
- `Scene3DProps` = `theme.scene3D`, spread into `<Car3D>` by theme components.
- **No `if (style === …)` anywhere.** Variation goes through the registry or CSS variables. Inside a theme folder you already know the theme — no checks needed.
- A theme folder imports only from `lib/*`, `components/*.tsx` (shared) and its own folder. Never from another theme folder.

## CSS theming
- Semantic variables: `--color-bg --color-surface --color-ink --color-ink-2 --color-accent --color-accent-2 --color-line --font-display --font-body --font-mono --radius`, plus motion `--ease --dur-fast --dur --dur-slow`.
- Defaults (Nocturne) live in `@theme` in `globals.css`. The other themes' overrides are **generated from the registry tokens** (`lib/theme-tokens.ts`) into a `<style>` tag in the root layout as `[data-theme="<id>"]{…}`. So tokens have one source of truth (TS), with the Nocturne defaults mirrored in `@theme` so Tailwind generates the utilities.
- Utilities that always resolve to the active theme: `bg-bg bg-surface text-ink text-ink-2 text-accent bg-accent text-accent-2 border-line font-display font-body font-mono rounded-theme ease-theme`.
- `data-theme` can be set on any element (the landing doors each set their own), not only `<html>`. `ThemeProvider` sets it on `<html>` for `/[style]/*`.
- Theme-specific CSS: `components/themes/<id>/styles.css`, imported by `globals.css`, **every rule scoped under `[data-theme="<id>"]`**. Keyframes prefixed with the theme id.
- Every animation must be disabled/reduced under `@media (prefers-reduced-motion: reduce)` (global safety net in globals.css + local handling for JS animations via `usePrefersReducedMotion()`).

## i18n
- IT default, EN complete. Dictionaries: `lib/i18n/it.ts` (defines the `Dict` type), `lib/i18n/en.ts` (`satisfies Dict`). Theme-only strings: `lib/i18n/themes/<id>.ts` exporting `{ it, en }`, mounted under `th.<id>`.
- `const t = useT(); t('builder.next')`, interpolation `t('x', { n: 3 })` with `{n}` in the string. `useLocale()` for the raw locale.
- Locale lives in the store (persisted), not in the URL. **No hard-coded user-facing strings in components** (brand names, model names, city names and numbers come from `lib/data.ts`).

## Shared logic (untouchable from themes; themes pass props only)
- `estimate(input, rates)` → `{ lines[], subtotal, onRequest[], total, currency, days }`. Always labelled "Stima indicativa · il concierge conferma in meno di un'ora" (`t('price.disclaimer')`). Use the `useEstimate()` hook.
- `buildMessage()` / `waUrl()` → `https://wa.me/393202934909?text=…`. Always show the text preview before the click (`<WhatsAppPreview>` in neutral or a themed equivalent).
- Store: `carId cityId deliveryType returnCityId dateFrom dateTo extras[] step` (+ `locale` in `useUI`). `validateStep(state, step)` returns `null` or an i18n key with the reason; Next is disabled and the reason is written.
- `useBuilderHydrated()` — persisted stores rehydrate after mount (`skipHydration`) to avoid SSR mismatches.

## Asset rules
- No brand logos drawn/reconstructed in code, no hotlinked photos, no downloaded 3D models.
- Exception: Marque uses official logo files placed by hand in `public/brands/{slug}.svg`; `BrandMark` falls back to typeset name if missing (manifest generated at build by `scripts/brands-manifest.mjs`).
- Photos: `public/media/` stays empty. `<Photo slot="…">` = gradient placeholder in theme tokens + real caption + small `[foto cliente]`.
- Grand Prix: no real liveries (no Gulf/Martini…), only original stripes/numbers.

## Performance / a11y
- One WebGL context per page (`Car3D` enforces a singleton; a second instance renders the silhouette fallback). No 3D on the landing.
- `Car3D` pauses offscreen (IntersectionObserver), disposes everything on unmount, falls back to `CarSilhouette` without WebGL or with reduced motion.
- AA contrast, visible focus (`:focus-visible` ring uses `--color-accent`), keyboard navigation in the builder, `aria-live="polite"` on the estimate.
- Must hold at 390 px width.
